✅ Key Allowed Items & Guidelines

  • • 小型機内持ち込み手荷物（45x36x20cm / 17.7x14.2x7.9in）は、全乗客に無料で含まれています。
  • • 大型機内持ち込み手荷物（56x45x25cm / 22.0x17.7x9.8in、最大15kg / 33lbs）は、特定の座席予約またはeasyJet Plusカード所有者のみ許可されます。
  • • モバイルバッテリーは100Whまでであれば、通常機内持ち込み手荷物として許可されます。
  • • モバイルバッテリーは101～160Whの場合、航空会社の承認が必要で、乗客1人あたり2個までに制限されます。

⚠️ Strict Restrictions & Pitfalls

  • • 指定された寸法を超える手荷物は追加料金の対象となり、預け入れ手荷物として扱われる場合があります。
  • • 160Whを超えるモバイルバッテリーは機内への持ち込みが厳しく禁止されています。
  • • モバイルバッテリーは常に機内持ち込み手荷物として携帯し、預け入れ手荷物には入れないでください。
  • • 機内持ち込み手荷物の液体は、100ml以下の容器に入れ、透明な再封可能な袋に入れる必要があります。

❓ Frequently Asked Questions (FAQ)

EasyJetの無料機内持ち込み手荷物のサイズは？
EasyJetの無料機内持ち込み手荷物（小型機内持ち込み手荷物）は、ハンドルと車輪を含めて45 x 36 x 20 cm（17.7 x 14.2 x 7.9インチ）を超えてはならず、前の座席の下に収まる必要があります。
EasyJetで大型の機内持ち込み手荷物を持ち込めますか？
はい、ただし「Up Front」または「Extra Legroom」の座席を予約している場合、easyJet Plusカードをお持ちの場合、またはFLEXI運賃の場合に限ります。最大サイズは56 x 45 x 25 cm（22.0 x 17.7 x 9.8インチ）で、重さは15 kg（33 lbs）を超えてはなりません。
EasyJetのフライトでモバイルバッテリーは許可されていますか？
はい、100Whまでのモバイルバッテリーは通常、機内持ち込み手荷物として許可されています。101～160Whのものは航空会社の承認が必要で、乗客1人あたり2個までに制限されます。160Whを超えるモバイルバッテリーは禁止されています。
